# Awwwards Animations

Use for:

- scroll animations
- hero animations
- reveal effects
- parallax
- micro-interactions

---

# Rules

- Use GSAP + ScrollTrigger
- Use gsap.context() for scoping
- Cleanup on astro:before-swap
- Keep animations smooth (60fps)
- Prefer simple timelines

---

# Constraints

- Avoid unnecessary libraries
- Avoid over-engineering
- Keep code minimal and readable
