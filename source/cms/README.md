# Porsche Reunions — Sanity CMS

Sanity Studio for the Porsche Reunions platform (submissions, moderation).

## Conectar a tu proyecto

Si ya tienes un proyecto en Sanity: **[guía paso a paso en docs/SANITY_SETUP.md](../docs/SANITY_SETUP.md)**.

Resumen: copia **Project ID** y **Dataset** desde [sanity.io/manage](https://sanity.io/manage) → crea `.env` en la **raíz** del repo con `PUBLIC_SANITY_PROJECT_ID` y `PUBLIC_SANITY_DATASET` → desde la raíz ejecuta `npm run dev:cms`.

## Commands

- `npm run dev` — start Studio dev server
- `npm run build` — build for deploy
- `npm run deploy` — deploy to sanity.studio

From repo root: `npm run dev:cms`
